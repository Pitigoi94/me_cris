And, to give you a little idea of ​​what can be done with this device, here it is description of the manufacturer: <a href="https://www.elecrow.com/wiki/CrowPanel_ESP32_1.28-inch_Round_Display.html">CrowPanel</a> ESP32 Display 1.28inch round screen uses ESP32-C3 as the main control, equipped with a 32-bit dual-core chip, and the highest clock frequency reaches 160 MHz. Supports 2.4G WiFi and BLE low-power Bluetooth, suitable for IoT, smart home and other fields.
This 1.28-inch round screen has a resolution of 240*240, IPS screen and 178° viewing angle, which can enjoy more vivid and realistic images at any angle. It supports capacitive touch and is responsive; it has custom buttons, REST, and BOOST buttons, and the UART serial port can upgrade the firmware. It supports Arduino IDE, Espressif IDF, Lua RTOS, Home Assistant/PlatformIO/Micro python, and supports the LVGL library. It can design the UI interface by yourself, which is an ideal platform for DIY projects.
